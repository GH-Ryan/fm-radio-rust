# 更新日志

## [0.1.0.0] - 2026-10-17

- 首个 Windows Store 版本，提供 Radio Browser 全球电台目录浏览与搜索。
- 支持流式播放及内置 MP3、AAC/AAC+、FLAC、WAV 和 Ogg Vorbis 解码，并显示 ICY 当前曲目信息。
- 支持收藏、音量和播放控制，以及从电台列表或收藏中随机播放。
- 提供中英文界面；收藏保存在本机，无账号、广告或遥测。

## [0.1.1.0] - 2026-10-17

- 标题栏新增最小化和最大化/还原按钮，按钮状态随窗口变化更新。
- 新增 Windows 一键开发启动和发布构建脚本，自动配置 MSVC 环境。
- 修复 Vite 在 Windows 上监视 Rust 构建目录引发的文件占用错误。
- 发布构建增加版本号、Git tag、README 和更新日志一致性检查。
