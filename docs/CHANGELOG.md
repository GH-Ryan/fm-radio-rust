# 更新日志

## [0.1.3.0] - 2026-11-01

- 与 0.1.2.1 相同的黑屏修复、播放时保持显示器唤醒和看门狗改进。
- 修正 MSIX 版本号：Store 要求 Revision（第四段）为 0，因此由 0.1.2.1 改为 0.1.3.0，解决包接受验证失败。

## [0.1.2.1] - 2026-11-01

- 修复播放失败时窗口整体黑屏：后端错误对象被直接作为 React 子节点渲染，导致整棵界面卸载；现在按错误码本地化显示，并增加渲染错误边界。
- 播放且窗口可见时阻止显示器休眠，减少熄屏后 WebView2 停止绘制；看门狗改为等待用户返回后再恢复，不再通过隐藏窗口触发重载。
- 保留睡眠唤醒后的自动续播，以及渲染心跳看门狗。

## [0.1.2.0] - 2026-10-31

- 修复系统睡眠或唤醒后窗口整体黑屏：看门狗检测到唤醒间隙或渲染冻结时，重建窗口合成器并重载页面。
- 唤醒后自动续播睡眠前正在播放的电台，连接尚未恢复时最多重试三次；用户已停止或暂停时不自动播放。
- 禁用 WebView2 的窗口遮挡计算与后台渲染挂起，减少窗口被遮挡或长时间挂起后停止绘制的情况。
- 播放期间提升音频相关线程的调度优先级（Windows MMCSS、macOS CoreAudio 独占、Linux 实时调度），降低与 Edge 等程序争用音频设备时的撕裂和卡顿。
- 构建流程收敛：版本号统一由 VERSION 驱动，Build-Release 默认同时产出 exe、MSIX 和校验清单，暂存目录移入 target 并在打包后清理，交付目录固定为 release。
- 工具脚本按 build、assets 分类，两个入口脚本保留在 tools 根目录；图标改为从 branding 单一源生成，不再手工维护多套位图。

## [0.1.0.0] - 2026-10-17

- 首个 Windows Store 版本，提供 Radio Browser 全球电台目录浏览与搜索。
- 支持流式播放及内置 MP3、AAC/AAC+、FLAC、WAV 和 Ogg Vorbis 解码，并显示 ICY 当前曲目信息。
- 支持收藏、音量和播放控制，以及从电台列表或收藏中随机播放。
- 提供中英文界面；收藏保存在本机，无账号、广告或遥测。

## [0.1.1.0] - 2026-10-17

- 标题栏新增最小化和最大化/还原按钮，按钮状态随窗口变化更新。
- 新增 Windows 一键开发启动和发布构建脚本，自动配置 MSVC 环境。
- 修复 Vite 在 Windows 上监视 Rust 构建目录引发的文件占用错误。
- 发布构建增加版本号、Git tag、README 和更新日志一致性检查。
